# Akash Portfolio
Personal portfolio website built with React, TypeScript, and Vite.

## Tech stack
- React 19
- TypeScript
- Vite
- Tailwind CSS
- MDX content for projects and space pages

## Project structure
- `client/` - frontend app (routes, sections, UI, styles)
- `content/` - MDX content for projects and space entries
- `server/` - production static-file server entry

## Prerequisites
- Node.js 20+
- pnpm 10+

## Getting started
1. Install dependencies: `pnpm install`
2. Start dev server: `pnpm dev`

## Scripts
- `pnpm dev` - run local development server
- `pnpm build` - build frontend and server bundles into `dist/`
- `pnpm start` - run production server from `dist/`
- `pnpm preview` - preview production frontend build
- `pnpm check` - run TypeScript type checks
- `pnpm format` - format files with Prettier
